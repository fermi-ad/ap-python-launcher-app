# ap_python_launcher_app

Flutter web UI for the AP Python Launcher.

## Getting Started

Fetch dependencies:

```bash
flutter pub get
```

Set up the pre-commit hook:

```bash
dart run tool/setup_git_hooks.dart
```

## Run

```bash
flutter run -d web-server --web-port 14500
```

## Test

```bash
flutter test
```

## Build (web)

```bash
flutter build web
```
